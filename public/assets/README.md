# Epsilon assets

The OAuth portal includes a local copy of the Epsilon mark supplied for this project and selected public illustrations from the upstream Epsilon repository.

- Upstream source: https://github.com/epsilon-social/epsilon/tree/epsilon-v0.6.1/public
- Upstream version: `epsilon-v0.6.1`
- Upstream repository: https://github.com/epsilon-social/epsilon
- Upstream project is licensed under GNU AGPL v3; see the upstream `LICENSE`.
- `epsilon-logo.svg` is the SVG logo supplied for this portal.
- `loading.svg` and `oops.svg` are copied from upstream `public/`.

This is an independent OAuth portal and is not an official Epsilon Social service.
